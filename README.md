# 班務助手

班主任本機工作台（繁體中文 PWA）：班別與學生名單、功課清單與交收、行為一句話記錄、總覽。

資料只存在你開啟此頁的瀏覽器，可匯出／匯入 JSON 備份。沒有登入、沒有雲端名單。

## 使用

1. 打開 [GitHub Pages 網址](https://dssfgs.github.io/banwu-assistant/)（需在 repo Settings → Pages 選 `main` / `/ (root)`）。
2. 或直接用瀏覽器開啟 `index.html`。
3. 手機可用「加到主畫面」當小型 App。

第一次是空的。可「新增班別」後批量貼名單，或在設定載入示範資料（含可編輯的行為記錄）。

## 批量名單格式

```
1 陳大文 男 91234567
2 李嘉欣 女
陳志明
```

## V1 範圍

- 學生：座號、姓名、性別、在學、家長電話、備註
- 功課：標題、類型、佈置／限期、已交／欠交／遲交（不分分數）
- 行為：日期 + 自由文字，可新增／編輯／刪除
- 多班切換、深色模式、本機備份

不做：課表、教學進度、登入帳號、操行積點。
